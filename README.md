# SmartDownYT

Десктопное GUI-приложение на Python для скачивания отрезка видео с YouTube:
задаёшь ссылку, выбираешь начало и конец через ползунки, качество — и получаешь
готовый файл нужного куска, без скачивания всего ролика целиком.

Автор: [kirai](https://kirai.kz) (KiraiSpace)

## Возможности

- Ползунки начала/конца отрезка + ручной ввод времени (`чч:мм:сс`)
- Выбор качества из реально доступных для конкретного видео разрешений
- Режим «только звук» — сохранение в mp3
- Два способа получить отрезок:
  - **Быстрый** — скачивается только нужный диапазон (`yt-dlp download_ranges`)
  - **Надёжный** — видео качается целиком во временную папку, отрезок вырезается
    локально через ffmpeg; включается автоматически, если быстрый способ падает
- Прогресс скачивания, скорость, ETA
- Лог операций прямо в окне

## Требования

- Python 3.9+
- [ffmpeg](https://ffmpeg.org/download.html) в `PATH`
  - Windows: `winget install Gyan.FFmpeg`
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`

## Установка

```bash
git clone https://github.com/<ваш-юзернейм>/<репозиторий>.git
cd <репозиторий>
pip install -r requirements.txt
```

## Запуск

```bash
python smartdownyt.py
```

1. Вставьте ссылку на видео → «Загрузить инфо»
2. Настройте начало/конец отрезка ползунками или полями ввода
3. Выберите качество и способ скачивания
4. Укажите папку сохранения → «Скачать отрезок»

## Известные нюансы

- YouTube периодически меняет формат отдачи потоков, из-за чего может появляться
  ошибка `HTTP 403`. Лечится обновлением yt-dlp:
  ```bash
  pip install -U yt-dlp
  ```
- Если ffmpeg падает с непонятным кодом завершения — проверьте, что используется
  стабильная сборка (а не ежедневный git-билд), и что антивирус не блокирует
  процесс.
