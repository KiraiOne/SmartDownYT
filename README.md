# SmartDownYT

YouTube желісінен видеоның қажетті үзіндісін жүктеп алуға арналған Python графикалық десктоп қолданбасы (GUI): видео сілтемесін қоясыз, басталуы мен аяқталуын жылжытқыштар (жүгірткілер) арқылы реттейсіз, сапасын таңдайсыз да — бүкіл видеоны толық жүктемей-ақ, тек қажетті кесіндісін аласыз.

**Авторы:** kirai (KiraiSpace)

---

## Мүмкіндіктері

* **Басталуы мен аяқталуын дәл орнату:** Жылжытқыштар (жүгірткілер) арқылы немесе уақытты қолмен енгізу (`сағ:мин:сек`) мүмкіндігі.
* **Сапасын таңдау:** Белгілі бір видео үшін қолжетімді нақты ажыратылымдықтар (360p, 720p, 1080p т.б.) анықталады.
* **«Тек дыбыс» режимі:** Тек аудионы MP3 форматында сақтау.
* **Үзіндіні жүктеудің 2 әдісі:**
  * **Жылдам (Quick):** Тек таңдалған аралық қана жүктеледі (`yt-dlp download_ranges`).
  * **Сенімді (Safe):** Видео уақытша қапшыққа толық жүктеліп, үзінді `ffmpeg` арқылы жергілікті түрде кесіледі (жылдам әдіс қате берсе, автоматты түрде қосылады).
* **Прогресті бақылау:** Жүктеу пайызы, жылдамдығы және ETA (қалған уақыты).
* **Журнал (Лог):** Барлық орындалған әрекеттер бағдарлама терезесінде көрініп тұрады.

---

## Талаптар

* **Python 3.9+**
* Жүйеде **`ffmpeg`** орнатылған болуы және **PATH** жолына қосылуы тиіс:
  * **Windows:** `winget install Gyan.FFmpeg`
  * **macOS:** `brew install ffmpeg`
  * **Linux:** `sudo apt install ffmpeg`

---

## Орнату

1. Репозиторийді көшіріп алыңыз:
   ```bash
   git clone https://github.com/KiraiOne/SmartDownYT.git
   cd SmartDownYT
```
```
2. Қажетті тәуелділіктерді орнатыңыз:
```bash
pip install -r requirements.txt

```



---

## Іске қосу

```bash
python smartdownyt.py

```

1. Видео сілтемесін қойып, **«Ақпаратты жүктеу»** батырмасын басыңыз.
2. Үзіндінің басталуы мен аяқталу уақытын жылжытқыштармен немесе енгізу өрістерімен реттеңіз.
3. Видео сапасын және жүктеу режимін таңдаңыз.
4. Сақтау қапшығын көрсетіп, **«Үзіндіні жүктеу»** батырмасын басыңыз.

---

## Белгілі нюанстар

* YouTube арасында ағындарды беру форматын өзгертіп отырады, соның салдарынан **HTTP 403** қатесі пайда болуы мүмкін. Мәселені шешу үшін `yt-dlp` кітапханасын жаңартыңыз:
```bash
pip install -U yt-dlp

```


* Егер `ffmpeg` белгісіз қате кодымен тоқтап қалса — жүйеде күнделікті git-сборка емес, **стабильді құрастырылым (stable build)** орнатылғанын және антивирустың процесті бұғаттамай тұрғанын тексеріңіз.
